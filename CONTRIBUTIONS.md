# Fork Contributions

## About This Fork

This repository is a maintained fork of [Firecrawl/anydoc](https://github.com/firecrawl/anydoc).

The original anydoc project provides a Rust-based document conversion library that transforms office documents into GitHub-Flavored Markdown.

## Improvements in This Fork
