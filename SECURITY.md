# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this fork, please avoid opening a public issue with sensitive details.

Provide:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

## Security Practices

This fork follows these practices:

- No secrets or credentials should be committed to the repository.
- Dependencies should be reviewed regularly.
- Changes should be tested before release.
- Security-related improvements should be documented.
